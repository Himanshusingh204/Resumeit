Resumeit

Upload one resume. Resumeit reads your keywords, scrapes the job boards for matching roles, and builds a separate, truthful, one-page tailored resume for the jobs you choose. You always apply yourself.

Overview

A private tool that runs on your own PC. No accounts, no cloud, no database server. Everything lives in one SQLite file.

1

Keyword extraction

AI reads your resume and proposes search queries from your real titles, skills and projects.

2

Scraping via JobSpy

LinkedIn, Indeed, Naukri, Glassdoor and Google, one board at a time so a block never stops the run.

3

Per-job resumes

Each JD gets its own resume, match score and list of gaps. Export as PDF, DOCX or HTML.

4

Nothing silent

Anything skipped, blocked or incomplete is written to an Issues log you can read.

How it flows

One click runs the whole chain. Each box can fail on its own without taking down the rest.

Base resumePDF / DOCX / txt → structured profile
Keywordsprofile → up to 5 search terms
Scrapefor each term × each board
Storededupe by URL, skip jobs with no JD
Tailorprofile + JD → resume + match
Guardsincomplete / invented facts rejected
Exportfit to 1 page · PDF · DOCX · HTML
Truthfulness ruleThe tailoring prompt may only reorder, select and reword facts already in your profile. Requirements you do not meet are reported as gaps, never invented.

Quick start

Windows, Python 3.12+. Edge or Chrome is used for PDF export.

python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
copy .env.example .env      # choose your AI provider
run.bat                     # opens http://127.0.0.1:8000
  1. Upload your base resume and check the parsed profile (editable JSON).
  2. Leave search terms empty to use resume keywords, or click Suggest from resume and edit them.
  3. Press Scrape + build resumes. Jobs and resumes appear live in the list.

Jobs folder

Every finished resume is also saved on disk, so you can open it and apply without the app.

jobs/2026-11-15/Kavaliro_Full-Stack-Engineer_48/
  jd.md          the job description, company, link
  match.txt      score, what you have, what is missing
  resume.pdf     tailored resume (template chosen at the top of the page)
  resume.docx    editable copy
  resume.html    same resume as a web page

The Jobs folder button opens it. A job link can also be pasted: the description is read from the page, then the resume is built. Jobs that share no skill with your resume are marked Low match and cost no AI call until you press Build anyway.

Guards & tracker

Rules from the plan, enforced in code and covered by tests.

WhatHow it works
Truth guardAfter the AI answers, every skill, company, title, date, degree, certification, project and every number must already exist in your profile. Otherwise the job is error with the reason, and nothing is saved. It cannot catch a fact turned around ("contributed" to "led"), so use What changed in the preview.
One pageThe AI is told to stay short. The PDF is then page-counted: type shrinks (never below 9 pt), then the least relevant project, bullet or skill is dropped (never added). If it still does not fit, the job shows Manual trim needed and an Issues entry. DOCX page count cannot be checked. Fix 2-page PDFs re-fits old resumes with no AI call.
Applied trackerPer-job dropdown: Applied, Interview, Rejected, Offer. Set only by you; the app, the daily scan and the MCP server never change it. Applied/Rejected leave the default list and appear under the Applied tab.
Level and location flagsRead from the job text without AI: 5+ yrs, clearance, no sponsorship. hide above my level hides jobs needing more years than your resume shows. Only a hint; nothing is deleted.
Salary and pre-apply factsEach card shows salary (job-board field, else read from the text: LPA, lakh, $, per month/hour are normalised), work mode, job type, age and warning tags (night shift, bond, unpaid, commission only, walk-in, relocation, immediate joiner). Filters: min salary (lakh INR, other currencies converted roughly), salary shown, mode, type, posted date, only my level (1 year slack), India or remote-if-abroad (jobs abroad must be remote and not US-citizen/clearance only), matches my resume skills: the last three are on by default. Hide warnings. A hint only: check the posting. The daily scan can skip known-low salaries with min_salary_lakh (unknown salary is kept).
What changedPreview button: removed skills/bullets, reworded bullets (with the original) and dropped projects against your base resume.
Cover letterOptional button per job, one AI call, same truth rule (numbers must be in your profile). Saved as cover_letter.md in the job folder.
ModelCLAUDE_MODEL (Claude Code), ANTHROPIC_MODEL, OPENAI_MODEL in .env. Build matching asks with the exact AI-call count first.
BackupBackup button downloads a zip of the database and jobs/.

Daily scan

Finds new jobs and prepares resumes. It never applies, submits or messages anyone.

PUT /api/saved-search   {"terms":["python developer"],"location":"Pune","max_resumes":5,"hide_senior":true}
scripts\install_daily_task.bat      # Windows Task Scheduler, 09:00 daily
.venv\Scripts\python -m app.scan    # or run it by hand

Limits: at most max_resumes AI calls per run, only for jobs that share a skill with your resume, and (by default) not above your level. Create data\STOP to halt a run before its next resume. Each run appends a summary to jobs/_daily.md. Remove the schedule with schtasks /Delete /TN ResumeitDailyScan /F.

MCP server

Lets Claude Desktop or Claude Code use Resumeit as a tool. It works on the same local database, no web server needed.

claude mcp add resumeit -- D:\path\to\resumeit\.venv\Scripts\python.exe -m app.mcp_server
ToolWhat
get_profile, list_jobs, get_job, list_issuesRead your resume, jobs (with flags and fit), failures

estimate_ai_calls, build_resume, what_changed, write_cover_letterOne resume or letter per call, with all guards

No apply tool, by designThere is no tool to apply to a job or to set Applied/Interview/Rejected/Offer. A test fails if one is added.

Failure handling

The rule: skip it, keep going, and write down what was skipped.

Issue kindWhenEffect
scrape_failedA board raised (429, captcha, network)That term × board skipped; others continue
no_resultsA board returned nothingLogged so you can tell blocked from empty
incomplete_jobsJob missing URL or descriptionJob not stored; count logged
keywords_failedAI could not extract termsRun stops with a message; type terms manually
tailor_failedAI error, incomplete resume, or the truth guard found an invented factJob marked error; redo button retries

Issues are visible in the UI (Skipped / incomplete) and appended to data/issues.log as tab-separated lines.

Limits & risks

Scraping is fragileLinkedIn and Naukri block quickly. Expect no_results or scrape_failed entries; proxies are not wired in.
Read before you sendThe truth guard catches new facts, not a fact bent out of shape. Use What changed and read each resume.
Cost and speedOne AI call per job, two in parallel. Large searches use proportionally more of your Claude / API quota.
Not coveredAuthentication (local only by design), a live OpenAI call (the test runs only when OPENAI_API_KEY is set), and browser-level UI tests.
