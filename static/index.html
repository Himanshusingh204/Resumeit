Set up a free AI (Google Gemini)

Resumeit needs an AI to read your resume and write tailored ones. Google Gemini has a free tier and needs no credit card.

  1. Get a free key. Open aistudio.google.com/apikey, sign in with a Google account, press Create API key and copy the key.
  2. Paste it in .env. In the Resumeit folder open the file .env (run.bat or run.sh creates it from .env.example). Write the key after GEMINI_API_KEY= with no spaces or quotes, and save.
  3. Restart Resumeit. Close the window it runs in and start it again. This label at the top turns green and says Gemini.

The free tier has daily limits, so build resumes for the jobs you really want. Claude Code, ANTHROPIC_API_KEY and OPENAI_API_KEY also work if you already have them.
